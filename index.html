Hubungkan ke Google Drive asli

Aplikasi ini berjalan murni di browser — tidak ada server yang menyimpan datamu. Yang dibutuhkan hanya OAuth Client ID dari Google Cloud (gratis, sekali saja):

  1. Buka Google Cloud Console → buat project baru → aktifkan Google Drive API.
  2. Buka APIs & Services → Credentials → Create Credentials → OAuth client ID → tipe Web application.
  3. Di Authorized JavaScript origins tambahkan origin situs ini (mis. https://drive-kamu.vercel.app). Untuk coba lokal: http://localhost:3000.
  4. Di OAuth consent screen isi nama aplikasi saja (mode Testing cukup untuk dipakai sendiri). Saat login nanti pilih Lanjutan → Buka … (tidak aman) — wajar untuk aplikasi testing milik sendiri.
  5. Salin Client ID-nya dan tempel di bawah.

Client ID tersimpan hanya di browser ini (localStorage). Token login tiap akun juga hanya di memori browser — tidak dikirim ke mana pun selain googleapis.com.
